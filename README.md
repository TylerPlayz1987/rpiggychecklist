# rpiggychecklist

Static checklist site for RPiggy collectibles with:

- 4 category tabs: Skins, Items, Effects, Build Mode
- Category content split into standalone files under `content/`
- Subtype tabs within each category
- Light and dark mode toggle with saved preference
- Update Log popup for viewing recent checklist changes
- Report Bug link for submitting issue reports
- Green highlights and local countdowns for collectibles with upcoming availability deadlines
- Local progress saving
- JSON export/import for backup and restore

## Usage

Open `/home/runner/work/rpiggychecklist/rpiggychecklist/index.html` in a browser.
